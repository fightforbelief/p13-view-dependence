# Historical magnitude audit

Design recorded before computing the historical endpoint results. The portfolio decision is the net tilt in the common manufacturing leg of three spreads (consumer, technology and health, each minus manufacturing). Use every January 1980–2025 inclusive, with preceding observations only. Describe 1980–1999 and 2000–2025 separately. Both windows use the September 2026 French data-library vintage. These are retrospective reconstructions.

Monthly returns are in decimal units. Use an equal-weight five-sector benchmark, risk aversion 3, a trailing 60-month sample asset covariance, and a forecast for each spread equal to its trailing 60-month mean. Set the normalized marginal view-error variances to the trailing 60-month sample variances of realized one-month-ahead spread forecast errors. For each of those forecast errors, use the forecast available at its own origin. This is a disclosed working scale in the BL update. Differences from realized returns include return noise.

Use the smallest dependence share containing the trailing forecast-error correlation, rounded **up** to the next hundredth, with an exact PSD check on the unrounded input covariance. Compare against all sign conventions of equicorrelation within the same share. Primary outcomes are the interval width for the common asset in percentage points, the width added beyond the restricted comparator and whether each interval crosses zero. Report both fixed periods and all origins. Report sensitivity to halving the allowed share and to imposing the original no-leverage benchmark budget only through the zero-sum spreads. Short sales remain allowed. Also compute conditional endpoints in the published eight-asset example at benchmark and double variance. No return-performance claim is tested.

The archive is https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/5_Industry_Portfolios_CSV.zip . The local CSV contains the value-weighted monthly table for 1970–2024. Those 660 rows cover both the 60-month forecast history and preceding 60 months needed to construct errors at the first origin.

Implementation clarification: all three spreads sum to zero, so net investment is one. Gross leverage can exceed one.
